# Restaurant Ordering and Reservation Management System

A console-based Restaurant Ordering and Reservation Management System developed using C#. This project aims to simplify restaurant operations through organized order processing, table reservations, payment management, and record keeping.

## About the Project

The Restaurant Ordering and Reservation Management System is designed to manage essential restaurant activities through a menu-driven interface. It uses Object-Oriented Programming (OOP), custom-built data structures, and file handling to organize and maintain restaurant records.

## Features

1. Order Management

- Create customer orders.
- Edit existing orders.
- Delete orders.
- Support dine-in and takeout orders.
- Manage priority orders.
- Calculate order totals.

2. Reservation Management

- View table availability.
- Reserve available tables.
- Manage customer reservations.
- Edit and cancel reservations.

3. Payment Management

- Generate customer bills.
- Calculate payment totals.
- Manage payment records.

4. History Management

- View previous orders.
- View reservation records.
- Maintain transaction information.

5. Admin Management

- Manage restaurant menu items.
- Add, modify, and remove menu entries.
- Maintain menu information through text files.

## Data Structures and Algorithms

This project implements custom-built data structures instead of relying on the built-in collection classes from "System.Collections.Generic".

| Data Structure | Purpose |
| --- | --- |
| MyList | Stores and manages collections of data. |
| MyStack | Implements Last-In, First-Out (LIFO). |
| MyQueue | Implements First-In, First-Out (FIFO). |
| MyPriorityQueue | Processes elements according to priority. |
| MySet | Stores unique elements. |
| MyMap | Organizes data using key-value pairs. |

## Data Storage

The system uses text files to store and maintain information, including:

- "menu.txt" – Restaurant menu records.
- "orders.txt" – Customer order records.
- "reservations.txt" – Table reservation records.

This allows stored information to remain available after the program is closed.
